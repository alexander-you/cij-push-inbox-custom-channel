# Known limitations

| Limitation | Impact | Reference |
|---|---|---|
| **Inbox API is anonymous (test harness)** | Anyone who knows an app key and a recipient key can read, mark or delete that recipient's inbox items, and register a browser for that recipient. Don't use it with real customer data until end-user authentication is added. | [security.md](security.md), [developer-integration.md](developer-integration.md#what-must-change-for-production) |
| **Function key from the plug-in** | The plug-in authenticates to the Channel API with a function key stored in a secured column. Managed identity is planned. | [security.md](security.md) |
| **Browser devices only** | `POST /devices` accepts Web Push subscriptions only. FCM and APNs registration is planned. | [developer-integration.md](developer-integration.md) |
| **No opened/clicked triggers yet** | The PWA marks items as read in Cosmos DB, but no CIJ custom trigger is raised. | [README roadmap](../README.md#roadmap) |
| **No delivery report for test sends** | CIJ test sends carry an empty `RequestId`, so the dispatcher can't report status for them. Journey sends are reported. | ([Custom channel custom APIs](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-custom-channel-custom-api)) |
| **Notification Hubs Free tier** | Free tier limits and no SLA; use Basic or Standard in production. | ([Notification Hubs pricing](https://azure.microsoft.com/pricing/details/notification-hubs/)) |
| **Cosmos DB region** | The template can place Cosmos DB in a different region from the other resources (`COSMOS_LOCATION`). Check data residency. | [installation.md](installation.md#41-create-the-azd-environment) |
| **Solution security roles not shipped yet** | Use System Administrator or System Customizer to configure channel instances. | [configuration.md](configuration.md#access) |
| **Cxp Channel Definitions Services User is often locked** | The post-import script can't grant it Read, and warns instead. CIJ access comes through Marketing Services User Extensible Role. | ([Custom channel instance](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-define-custom-channel-instance), [Channel instance account and Extensible role](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-define-channel-instance-account), [Managed properties](https://learn.microsoft.com/power-platform/alm/managed-properties-alm)) |
| **Microsoft role privileges may reset on CIJ upgrades** | Rerun `deploy/post-import.sh` after upgrades. | ([AddPrivilegesRole](https://learn.microsoft.com/power-apps/developer/data-platform/webapi/reference/addprivilegesrole)) |
| **`deliveryMode` option labels can't be localized** | The options show in English in every UI language; the Hebrew part description explains them. | ([Message parts](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-custom-channel-message-parts), [Custom channel localization](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-custom-channel-localization-admin)) |
| **Message part description limit** | `msdyn_description` is limited to 100 characters, so part help text is short. | ([Message parts](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-custom-channel-message-parts)) |
| **No channel account table** | Account tables aren't supported for custom channels, so each channel instance is configured on its own. | ([Custom channels in CIJ](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-extend-outreach-custom-channels), [Channel definition](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-define-channel-definition)) |
| **No inbound messages** | Inbound is documented for SMS only. Interactions come back as custom triggers instead. | ([Custom channel custom APIs](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-custom-channel-custom-api), [Custom triggers](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-custom-triggers)) |
| **Links can be shortened** | CIJ may shorten links in custom channel messages, and shortened links expire. | ([Create custom channels](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-create-custom-channels)) |
| **Test sends use the typed recipient** | For a test send, the inbox and push target is exactly the value typed in CIJ (normalized: lowercase, `+` and spaces removed). The browser must be subscribed with the same value. | ([Custom channel custom APIs](https://learn.microsoft.com/dynamics365/customer-insights/journeys/real-time-marketing-custom-channel-custom-api)) |
| **Asset-library images are public and cached** | Anyone with the URL can load the image. CDN copies, possibly outside the region, can stay for up to 30 days after an asset is replaced or deleted. Upload a new asset instead of replacing one. | [SEC-21](security.md#sec-21-message-images-from-the-asset-library), ([Asset library](https://learn.microsoft.com/dynamics365/customer-insights/journeys/upload-images-files)) |
| **Disabling the CIJ CDN breaks images** | The asset library becomes unavailable and images already sent show as broken. | ([Impact of disabling Azure CDN](https://learn.microsoft.com/dynamics365/customer-insights/journeys/cdn-disabling)) |
| **Upgrade from the plain-text image part** | An upgrade import keeps `msdyn_maxlength` = 1000 on the `imageId` part; clear it to match a fresh install. Messages saved with the old `imageUrl` part lose their image; select it again. | [data-model.md](data-model.md#image-resolution) |
| **Notification image shows only when expanded** | Verified on Android with Chrome and Samsung Internet: the image appears when the notification is expanded. The collapsed view shows only the PWA `icon` (the envelope), not the image. A paired Wear OS watch also showed the image. With Edge for Android, the first test showed no image in the notification, and it wasn't checked in the expanded view; the cause is **unverified**. Treat the image as supplemental: the inbox always shows it. | ([Android: expandable notifications](https://developer.android.com/develop/ui/views/notifications/expanded)) |
| **Contact-to-lead merges** | Inbox items aren't moved when records are merged. | — |
| **iOS web push** | It works only for web apps added to the Home Screen on iOS/iPadOS 16.4+. | ([Web Push on iOS](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)) |
